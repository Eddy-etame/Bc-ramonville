# Instructions pour les agents IA : /ai.txt

#   /admin/  — le vestiaire, l'outil du staff. Il porte déjà un
#              <meta robots="noindex, nofollow"> et un en-tête
#              X-Robots-Tag (vercel.json) : la triple ceinture est
#              volontaire, un `Disallow` seul n'empêche pas une URL
#              d'être indexée sans être lue.
#   /api/    — les points d'entrée de l'assistant et du registre de
#              contacts. Ce sont des réponses JSON, pas des pages ; les
#              explorer ne fait que brûler du budget de crawl.

# LE SERVEUR MCP EST OUVERT AUX AGENTS : Allow: /api/mcp
#
# Chaque groupe ci-dessous ferme /api/ — c'est voulu : l'assistant, le
# registre de contacts et l'admin n'ont rien a faire dans un index. Mais
# /api/mcp est la carte des auteurs du site, et elle doit etre lisible.
# RFC 9309 §2.2.2 : entre deux regles qui matchent, la plus SPECIFIQUE
# gagne (longueur du chemin). « /api/mcp » bat « /api/ ». Le Allow est
# ecrit en premier pour les parseurs qui s'arretent au premier match.
# ---------------------------------------------------------------------
